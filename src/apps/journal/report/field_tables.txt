Часть den

| Поле | Обязательно | Правила |
|---|---|---|
| `source` | нет | `model` — чем составлен отчёт, `files` — какие файлы разобраны, `messages` — сколько сообщений учтено |
| `title` | да | образ дня, 2–6 слов, до 60 знаков, без точки в конце |
| `lead` | нет | одно предложение о дне, до 240 знаков |
| `summary` | да | 2–4 предложения, до 600 знаков |
| `bullets` | нет | 3–6 строк по 140 знаков: самое важное фактами |
| `weather` | нет | `code` — одно из: `clear`, `sun_after_rain`, `clouds`, `wind`, `storm`, `fog`; `text` — до 60 знаков |
| `tempo` | нет | одно слово о ритме дня, до 20 знаков |
| `quote` | нет | `member`, `text` до 200 знаков без кавычек по краям, `about` до 80 знаков |
| `timeline` | нет | до 30 событий: `time` — `ЧЧ:ММ`; `kind` — `start`, `turn`, `win`, `call`, `question`, `finish`; `title` до 60; `text` до 240; `members` — ключи |
| `task` | нет | `title` до 120, `essence` до 240, `done` — ключи сдавших, `insight` до 240 |
| `achievements` | нет | до 5: `text` до 200, `who` — ключи (может быть пусто) |
| `attention` | нет | до 5: `text` до 200 — что осталось нерешённым в деле; `who` — ключи. Только о деле, не о людях |
| `numbers` | нет | до 4 цифр: `label` до 40, `value` — целое, `note` до 40 |
| `chat` | нет | та же сводка для общего чата: обычный текст до 3500 знаков, только факты пакета |
| `notes` | нет | сомнения; на сайте не публикуются |

Часть lyudi

| Поле | Обязательно | Правила |
|---|---|---|
| `people` | да | каждый человек — не больше одного раза |

| `morning.context` | нет | видение дня, до 400 знаков |
| `morning.goals` | нет | до 15 строк по 160 знаков, без нумерации |
| `morning.contract` | нет | до 200 знаков |
| `morning.callsign` | нет | качество дня: одно качество из слов самого человека, до 40 знаков |
| `evening` | нет | объект или null |
| `evening.sent` | да | как у утра |
| `evening.context_pct`, `goals_pct` | нет | целое 0–100 или null |
| `evening.extra` | нет | другие шкалы: {"бытие": 50} |
| `evening.text` | нет | итог, до 600 знаков |
| `evening.wins` | нет | до 4 строк по 160 знаков |
| `evening.unfinished` | нет | до 300 знаков |
| `evening.highlight` | нет | дословная фраза, до 200 знаков |
| `goal_steps` | нет | `goal` — `breakthrough`, `creative` или `unfinished`; `text` до 200 знаков |
| `strength` | нет | до 160 знаков |

Часть proekt

Часть svyazi

| Поле | Правила |
|---|---|
| `links` | до 40: `from` и `to` — ключи разных людей, `kind` — `support`, `push`, `thanks`, `answer`; `text` до 200 знаков |
