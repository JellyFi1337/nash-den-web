НАШ ДЕНЬ — НАБОР ДЛЯ САЙТА

favicon.ico — вкладки, закладки и старые браузеры; внутри 16, 32, 48, 64, 128 и 256 px.
favicon.svg — масштабируемая иконка современных браузеров.
favicon-16x16.png / 32x32 / 48x48 — растровые варианты для браузеров.
apple-touch-icon.png — 180×180, добавление сайта на домашний экран iPhone/iPad.
android-chrome-192x192.png / 512x512 — ярлыки Android и значки веб-приложения.
icon-maskable-512x512.png — безопасный вариант для системной обрезки в круг и другие формы.
mark.svg / mark-black.svg / mark-white.svg — настоящий векторный знак для любого размера.
mark-64.png … mark-1024.png — знак на прозрачном фоне.
mark.webp — знак, WebP без потерь и с прозрачностью.
logo-original.png — исходная надпись со знаком, 2172×724, прозрачный фон.
logo-360.png / 720 / 1440 — готовые размеры полного логотипа.
logo.webp — полный логотип, WebP без потерь с прозрачностью.
site.webmanifest — имя, цвета и иконки веб-приложения.
head-snippet.html — готовые теги для <head>.

Подключение в Django:
1. Скопировать содержимое набора в src/static/img/brand/.
2. Добавить теги из head-snippet.html в базовый шаблон.
3. При использовании {% static %} заменить адреса тегами Django, например:
   href="{% static 'img/brand/favicon.svg' %}"
4. В шапке использовать mark.svg: он остается четким при масштабировании.
5. После изменения favicon браузеру может понадобиться перезагрузка с очисткой кеша.

Векторный знак заново построен по геометрии исходного дизайна. В маленьких favicon
тонкая линия убрана ради четкости. Для браузера знак размещен на светлом поле,
поэтому виден в светлой и темной теме. Иконки Apple/Android имеют непрозрачный фон.
SVG надписи не включен: полный логотип доступен в PNG и WebP; знак — в настоящем SVG.
Манифест сам по себе не добавляет офлайн-режим и не гарантирует установку как PWA.
Исходный код сайта в рамках подготовки набора не изменялся.
