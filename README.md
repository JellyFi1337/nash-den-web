# Наш день

Закрытый сайт команды и бот в Telegram: дни и записи людей, цели, общественный проект, банк штрафов, поиск опубликованного и недельные итоги. Django 5.2, PostgreSQL 17, aiogram 3; всё запускается в Docker.

Версия 2.0.0: секции 27–38 плана версии 2.0 выполнены, финальная приёмка пройдена. Номер версии — в `pyproject.toml`, история изменений — [CHANGELOG.md](CHANGELOG.md).

## Запуск на Windows

Docker Desktop должен работать. Из папки проекта:

```powershell
.\dev.ps1 up
.\dev.ps1 check
```

Если `.env` отсутствует, `up` создаст его из `.env.example`. Сайт: http://localhost:8000. Код дня: `.\dev.ps1 manage daycode`. Админка — путь из `DJANGO_ADMIN_PATH`, собственный вход Django. Бот запускается отдельно: `.\dev.ps1 bot`; журналы с выходом — `.\dev.ps1 logs`.

## Режимы данных

`demo` и `real` очищают данные команды после сводки и резервной копии. `demo` создаёт вымышленные данные; `real` загружает `private/team.json` и отчёты, затем читает таблицу. Невосстановимые сообщения и отчёты требуют точного `--confirm-delete=N`; не подтверждайте удаление настоящих накопленных данных ради проверки. Используйте отдельный стек по [PLAN A5](docs/PLAN.md#a5-изолированный-стек-для-проверок). Расписание загружается отдельно: `.\dev.ps1 manage load_schedule`. Источники — [INITIAL_DATA.md](docs/INITIAL_DATA.md).

Рабочая среда остаётся real. Новые секреты — только в `.env`; файлы `private/` и копии базы вне Git. Таблица только читается. Бот отправляет только в личку, код по запросу; утренняя рассылка выключена по умолчанию.

## Известные ограничения

- Код дня общий: сайт не знает, кто именно вошёл. Защита — смена кода в 05:00, сброс сессий, пауза после неверных попыток.
- Сайт работает по HTTP по IP без сертификата (DECISIONS 043): код и cookie входа идут открытым текстом. Переход на HTTPS — [DEPLOY, раздел 12](docs/DEPLOY.md#12-переход-на-https).
- На HTTP недоступны возможности безопасного контекста: кнопки «вставить» на входе и «Поделиться» у карточки цитаты скрыты, карточка сохраняется файлом. Вход из Telegram (Mini App) требует HTTPS; веб-версия Telegram сессию во фрейме не сохраняет.
- Бот не в группе (044): живых отметок «на связи» нет, пульс и «команда сегодня» показывают последний опубликованный отчёт с его датой. Бот не пишет в группы, не расшифровывает голос и видео, об удалённых сообщениях не узнаёт.
- Настройки вида (тема, палитра, фон, движение, размер текста) хранятся в браузере: на другом устройстве и после очистки данных сайта — снова по умолчанию.
- Таблица только читается. Телефон, адрес и состав семьи не читаются. Строка с неизвестным или неоднозначным именем не показывается; переименованный заголовок столбца перестаёт находиться до совпадения с [SHEET.md](docs/SHEET.md).
- Банк штрафов берёт сумму из таблицы; сайт штрафы не начисляет. Прогноз порога — простое среднее за последние семь дней, а не обещание.
- Поиск ищет только опубликованные отчёты и записи людей; сообщения чата и заметки для владельца не ищутся.
- Архив выгрузки больше 45 МБ режется на последовательные части одного файла.
- Конец потока — 22.11.2026; сроки целей «к 17 ноября» — отдельная дата. День в шапке считается по ступени из настроек сайта (056).
- Нет офлайн-режима и установки как приложения (нужен HTTPS), личных кодов, записи утра и итога на самом сайте и обращения к нейросети без владельца.
- Выпуск 2.0.0 проверен локальной продакшен-сборкой в режиме HTTP. На сервере Ubuntu развёртывание выполняет владелец по [DEPLOY.md](docs/DEPLOY.md).

Публичная копия рабочего репозитория: история изменений осталась в приватной версии.
