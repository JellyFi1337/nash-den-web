# Конфигурация чатов: `chats.toml`

Файл лежит в папке `private/`: `private/chats.toml`. Он содержит настоящие имена людей, поэтому в git и в образ Docker не попадает. В контейнеры папка монтируется только для чтения, путь внутри — `/app/private/chats.toml` (переменная `CHATS_CONFIG`). Образец — `chats.example.toml` в корне проекта.

Роли тем после каждого чтения файла копируются в базу (`Topic.role`): по ним сайт находит тему `journal`, не разбирая файл на каждой странице.

Бот хранит сообщения **всех** чатов и тем, куда он добавлен. Файл определяет только то, что из сохранённого выгружается и кому как называться.

## Что в файле

| Раздел | Назначение |
|---|---|
| `version` | версия формата, сейчас `1` |
| `[[chats]]` | чат: `id` (число вида `-100…`) и `name` |
| `[[chats.topics]]` | тема чата: `thread_id`, `name`, `file`, `role`, `export`, `ai` |
| `[people]` | соответствие «ключ человека = Фамилия Имя» |

Поля темы:

| Поле | Значение |
|---|---|
| `thread_id` | номер темы; `0` — тема General и чаты без тем |
| `name` | название темы, как в Telegram |
| `file` | имя файла выгрузки латиницей, без расширения |
| `role` | `journal` — декларации и итоги; `project` — общественный проект; `task` — задания и инсайты; пусто — прочее |
| `export` | выгружать ли тему в txt |
| `ai` | нужна ли тема нейросети для отчёта: такие файлы перечисляются в инструкции из архива |

Роль `journal` разрешена не более чем одной теме: по ней сайт считает живые отметки. В текущем режиме лички файла может не быть; тогда главная показывает последний отчёт с датой. Настройка сбора в группе ниже — только для будущего режима по решению владельца.

Ключ человека в `[people]` — имя пользователя Telegram строчными буквами без `@`. Если имени пользователя нет — `id` и числовой идентификатор: `id123456789`.

**Правило выгрузки:** сообщения людей, которых нет в `[people]`, не попадают в txt-файлы. В базе бота они при этом хранятся.

## Как заполнить

1. Добавьте бота в чат (права — в `docs/BOT_SETUP.md`). Пусть в каждой теме появится хотя бы одно новое сообщение.
2. Напишите боту в личку `/chats` — он покажет идентификатор чата, номера и названия тем, сколько сообщений сохранено.
3. Напишите `/people` — он покажет всех, чьи сообщения видел: имя пользователя, имя в Telegram, идентификатор.
4. Скопируйте `chats.example.toml` в `private/chats.toml` и заполните. Бот перечитает файл сам в течение минуты; сразу — `.\dev.ps1 manage apply_chats_config` или перезапуск бота.
5. `/chats` покажет, какие темы найдены в файле, а какие нет; `/people` — кого нет в `[people]`.

Ошибки в файле (неизвестное поле, повтор темы, две темы `journal`, повтор имени файла) бот называет при запуске и в ответе на `/chats`.

**Без бота в группе (секция 39).** Номера тем и отправителей даёт загрузка `result.json` из Telegram Desktop: бот (или `manage.py import_chat_export`) отвечает списком тем «номер · название · сообщений · людей · роль» и неузнанных отправителей «имя · Telegram ID · сообщений». Название есть только у темы, созданной внутри периода выгрузки; остальные подписаны «тема N» — назовите их сами по Telegram. Ключ человека без имени пользователя — `id` и Telegram ID из этой сводки; тому же участнику в админке стоит заполнить поле «Telegram ID» — тогда ключ в разделе «КОМАНДА» и в файлах совпадёт, а бот узнает его при `/start`. Импорт сам Telegram ID не записывает: совпадение имени — не доказательство. После правки файла выполните `apply_chats_config` — роли перейдут в базу.

## Формат выгрузки txt

Один файл на тему: `<file>.txt`. Команда `/export` собирает файлы в архив `export-<период>.zip` и кладёт в него `00-instrukciya.md` — инструкцию для нейросети (`docs/REPORT_FORMAT.md`).

```
[29.09.2026 16:34] Демина Лада: текст сообщения
[29.09.2026 17:24] Орлов Марк в ответ Демина Лада:
> начало исходного сообщения, до 60 знаков…
текст ответа
[29.09.2026 15:04] Демина Лада: [ Видеосообщение ]
[29.09.2026 15:10] Орлов Марк: [ Фотография ] подпись к фото
```

- Время — московское.
- Имя — из `[people]`.
- Ответ на сообщение человека, которого нет в `[people]`, выгружается без строки «в ответ».
- Исправленные сообщения выгружаются в последней редакции.
- Голосовые и видео не расшифровываются: бот видит только сам факт сообщения.
