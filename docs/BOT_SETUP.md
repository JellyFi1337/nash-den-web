# Бот: создание, права и первичная настройка

> В этой версии бот работает **только в личке** (DECISIONS 044): в группу его не добавляют, `/setjoingroups` → `Disable`. Разделы про группу ниже — на будущее, когда бота можно будет пригласить. Без группы `/export` присылает одну инструкцию, сообщения нейросеть берёт из выгрузки Telegram Desktop.

Бот делает три вещи:

1. в личных сообщениях присылает участникам код дня и открывает сайт;
2. **молча** сохраняет сообщения всех чатов и тем, куда добавлен, — в чаты он никогда ничего не пишет;
3. владельцу в личке выгружает истории чатов в txt и принимает готовый отчёт нейросети для публикации.

Нужны два бота: **тестовый** — для разработки и **рабочий** — для команды на сервере. Пока сервера нет, один бот может быть и тем и другим.
Токены в репозиторий не попадают: они хранятся только в `.env`.

## Имена

| | Название | Имя пользователя |
|---|---|---|
| Рабочий | Наш день · код дня | `nash_den_kod_bot` |
| Тестовый | Наш день · тест | `nash_den_test_bot` |

Свободны ли эти имена, покажет только BotFather. Запасные варианты: `nashden_kod_bot`, `nash_den_9_bot`, `nashden_dkr_bot`. Имя должно заканчиваться на `bot`.

## Создание (для каждого бота)

1. В Telegram откройте `@BotFather` (с синей галочкой) и отправьте `/newbot`.
2. Введите название, затем имя пользователя из таблицы.
3. BotFather пришлёт токен вида `123456789:AA…`. Запишите его в `.env`: `TELEGRAM_BOT_TOKEN=…`, а имя без `@` — в `TELEGRAM_BOT_USERNAME=…`.
4. Узнайте свой числовой идентификатор Telegram (например, у `@userinfobot`) и запишите в `.env`: `TELEGRAM_OWNER_ID=…`. Только этот пользователь получит команды владельца.

## Настройка в BotFather

1. **Режим приватности** — для будущего сбора в группе, в текущем режиме лички не влияет: `/setprivacy` → выбрать бота → `Disable`.
2. **Описание**: `/setdescription` → «Присылаю код дня для входа на сайт команды и открываю сайт.»
3. **Короткое описание**: `/setabouttext` → «Код дня команды „Мир возможностей“».
4. **Команды**: `/setcommands` → отправьте две строки:

   ```
   start - начать и получить код дня
   code - код дня
   ```

   Команды владельца в это меню не добавляются — их видит только владелец по `/help`.
5. **Картинка**: `/setuserpic` → отправьте файл `src/static/img/brand/android-chrome-512x512.png` (знак на светлом поле, без прозрачности).

## Права в группе

Сообщество — супергруппа с темами («Контексты/Итоги», «ОП», «Отдел СМИ» и другие). Боту нужно только читать.

**Рекомендуемый способ — обычный участник, без прав администратора:**

1. Сначала отключите режим приватности (шаг 1 выше). Если бот уже был в группе — удалите его и добавьте заново: настройка применяется при добавлении.
2. Добавьте бота в группу как обычного участника: «Добавить участника» → имя бота.
3. Больше ничего не нужно. Бот будет получать сообщения всех тем, включая закрытые для записи.

**Если бот не получает сообщения** — сделайте его администратором и снимите все галочки прав (изменение профиля, удаление сообщений, блокировка, приглашения, закрепление, управление темами, добавление администраторов). Администратор получает все сообщения независимо от режима приватности; сами права боту не нужны.

Что важно знать:

- Бот видит сообщения только с момента добавления. Старую историю можно загрузить из JSON-выгрузки Telegram Desktop командой `import_chat_export` (см. `docs/PLAN.md`, A11.6).
- Об удалении сообщений Telegram ботам не сообщает: удалённое в чате останется в базе бота.
- Голосовые и видео бот не расшифровывает — сохраняется только отметка, что они были.
- Отправить что-либо в группу бот не может: это запрещено в его коде.
- После того как бот добавлен в чат команды, запретите добавлять его в чужие группы: `/setjoingroups` → `Disable`.
- Участников стоит предупредить, что сообщения чата сохраняются для составления ежедневного отчёта.

## Конфигурация чатов

1. Запустите бота: `.\dev.ps1 bot`. Пусть в каждой теме появится хотя бы одно новое сообщение.
2. Напишите боту в личку `/chats` и `/people` — он покажет идентификаторы чата и тем и список отправителей.
3. Скопируйте `chats.example.toml` в `private/chats.toml` и заполните по `docs/CHATS_CONFIG.md`. Бот перечитает файл сам.

## Участники

1. В админке сайта у каждого участника заполните имя пользователя Telegram.
2. Каждый участник один раз открывает бота и нажимает «Начать» (`/start`): без этого Telegram не позволит боту написать человеку первым.
3. Код бот выдаёт по запросу: `/start`, `/code` или любое сообщение. Утренней рассылки нет. Кнопка меню «Открыть сайт» появляется только на рабочем сервере с HTTPS; под сообщением с кодом кнопки нет — там ссылка.

## Ежедневный цикл владельца

1. `/export` — архив за вчера: в текущем режиме лички только `00-instrukciya.md`; txt тем есть при сохранённых сообщениях и настроенной выгрузке.
2. Отдайте нейросети инструкцию и свою выгрузку Telegram Desktop; при сборе в группе — файлы, перечисленные в разделе «ФАЙЛЫ».
3. Нейросеть вернёт от двух до пяти файлов JSON: «день», «люди» и, если есть данные, «проект», «голоса», «связи». Сохраните каждый блок в свой файл.
4. Отправьте файлы боту — по одному или архивом. Он проверит каждый и покажет сводку.
5. Когда приняты «день» и «люди», нажмите «Опубликовать» — отчёт появится на сайте. Остальные части можно дослать позже.

Подробности и второй способ (через админку) — в `docs/REPORT_FORMAT.md`, раздел 8.

Дополнительно (секция 39): файл `result.json` из Telegram Desktop, отправленный боту, загружает историю чата — после настройки `chats.toml` `/export` присылает txt по темам и настоящие «ФАКТЫ» (`docs/OPERATIONS.md`, «Режим B с загрузкой истории»). `/week` или `/week 3` — набор для «Недели словами»; ответ нейросети отправьте боту и нажмите «Опубликовать неделю». Файл `{"events": [...]}` — добавки расписания. Владельцу эти команды доступны без `/setcommands`; при желании добавьте строку `week - неделя словами` в список команд.

## Если токен попал в чужие руки

`/revoke` в BotFather → выбрать бота → записать новый токен в `.env` → перезапустить бота.
