# Вид и поведение «Нашего дня»

Действующая система после секций 27–35. Источники точных значений: `src/static/css/`, `src/static/js/`, `src/templates/`. Эталоны `docs/design/reference/` сохраняются; последующие решения владельца и этот документ описывают актуальный интерфейс. История — [DECISIONS.md](DECISIONS.md).

## 1. Идея

«Из шума — в ясность»: крупные числа, короткие подписи, воздух, видимые шаги людей. Один сильный цветовой акцент в группе карточек. Без оценок человека, стыда и рейтингов. Пустота данных объясняется спокойно; неизвестное не превращается в ноль. Сводки, цели и цитаты не сочиняются интерфейсом.

## 2. Цвет, тема и бренд

Единственный источник цветов — `tokens.css`. Значения ниже — базовая светлая палитра; в компонентах используются переменные, а не копии кодов цвета.

| Фирменный токен | Базовое значение | Смысл |
|---|---|---|
| --ink / --ink-2 | #0B0B0C / #1A1A1E | фирменный чёрный, заливки и текст цветных карточек |
| --hot | #FF4A1C | тёплый акцент, шкала целей |
| --lime / --lime-deep | #CFFF3D / #9FD400 | прогресс и кольца |
| --blue | #2D4BFF | поддержка и фокус |
| --bg / --paper / --mute / --line | #F4F2EC / #FFFFFF / #6A6A70 / #D9D6CC | базовые совместимые токены |

| Смысловые токены | Использование |
|---|---|
| --fg, --fg-mute | текст и подписи на странице/бумаге |
| --surface, --surface-edge | карточка и рамка |
| --surface-ink, --surface-ink-edge, --on-ink, --on-ink-mute | глубокая карточка, рамка и текст |
| --solid, --on-solid | контрастные кнопки/плашки |
| --page, --track, --track-ink, --focus | фон по времени суток, дорожки, фокус |
| --hot-fill/edge/text/soft, --lime-fill/edge/soft/bar, --blue-fill | палитра карточек и отметок |
| --avatar-bg/fg, --nav-bg/fg, --mark-bg/fg | лица, навигация, выбранная дата |
| --future, --wait-ring, --todo-edge, --skeleton, --score-edge | неизвестное, ожидание и границы |
| --scrim, --hairline, --spot*, --ripple, --flash*, --scan* | подложки и эффекты |
| --gate-fg, --gate-mute | постоянный тёмный экран входа |

`--ink` остаётся фирменным чёрным и не становится белым в тёмной теме. Обычный текст использует `--fg`. На тёплой и лаймовой карточках текст `--ink`; на синей — светлый.

Палитры: **мягкая** (soft, по умолчанию: --hot-fill #F8CBB5, --lime-fill #E4EEBE), **яркая** (vivid: чистые hot/lime), **тихая** (quiet: тёплый и оливковый серый, приглушённый синий). Тема независима: light/dark/auto, по умолчанию auto по prefers-color-scheme. В dark страница #111113, бумага #1A1A1E, текст #F2F0EA, подписи #A4A4AB, рамка #34343B. Вечер/ночь слегка меняют фон. Все сочетания темы/палитры проверяет test_tokens.

Шапка использует неизменный `img/brand/mark.svg` и текст «наш день». На входе знак тот же. При загруженном логотипе используется /logo/, открытый до входа. Полный логотип на страницах ошибок требует принудительно светлой темы; вход остаётся тёмным. Нельзя перерисовывать, перекрашивать бренд или удалять эталоны.

## 3. Типографика

Локальные woff2: Inter Tight для заголовков/чисел, Onest для текста, JetBrains Mono для меток и времени; font-display:swap. Токены --font-display/text/mono. Основной размер 16px; выбор размера 1/2/3 даёт множитель 1/1.15/1.3 через rem. Крупное число и единица — отдельные элементы, не переносить внутри числа.

Заголовки balance, абзацы pretty, узкие тексты hyphens:auto при lang=ru; метки/числа/имена manual. Время и суммы — tabular-nums. Фильтр typo меняет только вывод: NBSP после коротких слов, перед тире и частицами, между числом и единицей; не меняет URL/email, идемпотентен, сохраняет автоэкранирование. Не применять к вводу и json_script. Тексты владельца в разделе 8 записаны дословно, без вставленных NBSP.

## 4. Каркас и страницы

Колонка `.shell` ограничена 75rem. Карточки `.card`, радиус --r-card=1.5rem, рамка --bw=1.5px, зазор --gap=.75rem; кнопки/плашки скруглены. Основной desktop-переход 60rem; телефон — одна колонка. Нижняя плавающая навигация оставляет место внизу, учитывает safe-area. Шапка содержит ступень/день, меню вида и поиск; подпись потока берётся из SiteConfig.

Главная `.bento` адаптируется к отсутствующему проекту/средним/достижениям; не держит пустую половину карточки. Карточка проекта: SVG-кольцо доли готового чек-листа с сервера, срок, ближайшее решение, шаг последнего отчёта и «проект →», только при данных. Пульс без живого источника — последний отчёт с датой и приглушённым стилем, строки команды тоже с этой датой, без эффектов живого события.

Страница дня: лента дат, образ, сводка, люди, цитата, лента суток, задание, голоса, связи, проект, числа/внимание — только наполненные блоки. Без цитаты сводка расширяется. `day_nav.html` сверху и снизу: предыдущий день, все дни, следующий; недоступные края без ссылок. Свайп и стрелки пропускают интерактивные поля. Липкое оглавление: сторож is-stuck, активный блок aria-current через IntersectionObserver, плашка видна в горизонтальной ленте; scroll-margin-top учитывает измеренную высоту оглавления.

Ритм команды: до 14 опубликованных дат и сегодня при отметках. x — тихая точка «отчёта нет»; 0 — пунктир «итога нет»; прочие уровни отражают имеющиеся данные. Легенда и подсказки обязательны. График человека: контекст/цели, разрывы пропусков, пунктир среднего команды, легенда и текстовое описание; точки доступны мышью и клавиатурой. Календарь: уровни x/1/2/3 — нет данных/меньше половины/от половины/все итоги; будущие без ссылки, сегодня обведено.

Неделя: границы и навигация day_nav со свайпом; заполненные дни, средние, доля итогов, банк, планы, достижения, голоса и подвижки. Длинные списки раскрываются через details. Ссылки из дня, календаря и статистики; будущие недели не открываются. Статистика использует сетку по содержимому, без пустых половин.

Летопись (секция 39): опубликованная «Неделя словами» — карточка `.week-story` во всю ширину вверху недели (образ, лид, разделы, голоса со ссылкой на день, «впереди»). «Альманах потока» `/almanac/` — список глав `.almanac` по неделям: образ и лид недели и строки образов дней в виде `.week-day`. «Задания потока» `/tasks/` и «Голоса потока» `/voices/` — карточки в `.week-grid`; облако слов потока повторяет `.words` дня, цифра — число дней. Три страницы связаны плашками `archive-nav` (текущая — заливка `--solid`), ссылки ведут из календаря, статистики, недели и блока задания дня. Нижнее меню не меняется. На странице проекта «отделы · по дням» — карточка на отдел со свежим днём и `details` «ранее». У человека «качество и слова дня · по дням» — строки `.quality-row` (дата, «качество», слова дня), семь последних, остальные в `details`. Люди в отчёте названы ключами Telegram — на страницах показываются короткие имена.

## 6. Движение и сцены

Системное prefers-reduced-motion имеет приоритет; спокойный режим останавливает фон, убирает прокрутку цифр, эффекты и переходы. Для завершения JS-эффектов есть страховки; проверять в видимой вкладке. View Transition ready.catch сохраняется при пропуске. Новые повторяющиеся эффекты не добавляются; ниже перечислены и уже существующие циклы.

|---|---|---|

| Сцена | Авто по Москве при rollover=05:00 | Рисунок |
|---|---|---|
| утро | 05:00–11:59 | лучи рассвета, пылинки, свет |
| день | 12:00–17:59 | потоки тонких линий в слоях, сигналы-кометы |
| вечер | 18:00–23:59 | тёплые волны/полосы, кометы |

Силы off/quiet/normal/bright соответствуют 0/.55/1/1.6. На широком экране с точным указателем фон запрашивает кадры без дополнительного ограничения, на телефоне шаг не чаще ~32мс; DPR ограничен 1.5. Неизменные градиенты кешируются до resize/темы/палитры; движущиеся шлейфы пересчитываются. Цвета холста — вычисленные токены, в dark свечение lighter. При скрытии останавливается, после возврата не прыгает по времени.

## 7. JavaScript и CSS

`early.js` применяет настройки и страховку появления до отрисовки; `app.js` подключает модули литеральными относительными импортами для манифеста collectstatic. Модуль инициализируется только при своих элементах. Inline JS запрещён; данные сервера — json_script.

| Модули в static/js/modules | Назначение |
|---|---|
| prefs, settings, prefs-sheet, background-policy | настройки, меню/жесты, чистое правило экономии |
| motion, time | спокойный режим/переходы, серверная опора часов |
| ambient, spotlight, fx, haptics | сцены, свет/касание, частицы, вибрация |
| gate, ripple | вход, повтор заставки, волна |
| pulse, odometer, celebrate, toast | опрос с 401, числа, празднование живых отметок, очередь |
| reveal, roll, clock | первое появление данных, разряды, часы/отсчёты |
| copytext | кнопка «Скопировать» у текста для общего чата: буфер обмена или выделение с подсказкой |
| heat | подсказки ритма и точек графика |
| hscroll, daytoc, swipe | горизонтальные ленты, липкое оглавление, навигация |
| member-transition | переход одного выбранного аватара/имени |
| search, sharecard | поиск и PNG цитаты |

CSS: tokens — цвета/шрифты/масштаб; base — типографика/база; components — компоненты; layout — сетки/каркас; day — день/календарь; gate — вход; motion — эффекты; search — dialog; ui-page — образцы. Новых сырых цветов вне tokens нет, кроме явно разрешённых тестом служебных значений и неизменного бренда.

## 8. Тексты интерфейса

Тон спокойный, конкретный, без «нарушил», «провал», «отстаёт», сравнений людей и военной лексики. «Качество дня» — действующая подпись callsign. Авторские цитаты не редактировать. Деньги — «банк штрафов», без смысла копилки. Все новые формулировки фиксируются в DECISIONS; смысл существующих не менять без запроса.

## 9. Доступность и устойчивость

Контраст обычного текста ≥4.5:1, крупного ≥3:1; пары токенов проверены автоматическим стражем в обеих темах/трёх палитрах. Цель касания ≥44px, focus-visible, иконки с aria-label, графики с описанием/легендой, одометр без чтения всех разрядов. Исключение календаря на 320px (041): семь колонок, клетки уже 44px, минимум AA 24px сохраняется.

Dialog закрывается Esc и возвращает фокус. Мобильное меню держит Tab по кругу; смахивание закрывает при ~80px или скорости ≥.6px/мс с минимальным смещением 24px. Нативные details/формы/ссылки остаются доступны без JS; поиск и PNG требуют JS. Превью PNG — data:, blob только временная download-ссылка, без расширения img-src. Поделиться скрыто на HTTP, даже безопасном localhost; вставка кода на localhost доступна при readText.

## 10. Проверка изменений

Demo/real, 390/1280, обе темы/три палитры; дополнительно 320/768/1440, масштаб 3, спокойное движение, клавиатура, пустые состояния и продакшен-манифест. Сверять реальное содержимое, не маскировать переполнение обрезкой. Персональные данные на снимках не переносить в репозиторий/отчёт. Результаты и ограничения фиксируются в PROGRESS.

## 11. Чего не делать

Не заменять неизвестное нулём, не сочинять сегодняшние отметки и не праздновать цифры последнего отчёта. Не превращать банк штрафов в достижение, копилку или рейтинг людей. Не менять защищённые строки владельца, знак и эталоны. Не вводить новые цвета вне токенов, шрифты, библиотеки холста, встроенные скрипты или blob: для изображения. Не добавлять новые бесконечные эффекты; не скрывать переполнение обрезкой и не менять порядок карточек телефона ради сетки компьютера.
