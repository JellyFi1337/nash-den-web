# Шрифты

Файлы в этой папке — открытые шрифты под лицензией SIL Open Font License 1.1:

- Inter Tight — заголовки и цифры;
- Onest — основной текст;
- JetBrains Mono — подписи, время, коды.

В каждом файле два набора знаков: `cyrillic` и `latin`. Это вариативные шрифты: один файл покрывает все нужные начертания.
Подключение описано в `../fonts.css`.
